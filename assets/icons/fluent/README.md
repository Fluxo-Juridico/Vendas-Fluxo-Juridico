# Fluent System Icons

Official Microsoft Fluent System Icons, 20 px regular variants, used as local SVG masks in the document ribbon. Source: https://github.com/microsoft/fluentui-system-icons/tree/main/assets. Downloaded 2026-10-09. MIT license included in LICENSE. File names are normalized for the command map; SVG paths are unchanged.

Shared navigation and product icons use the official 24 px regular variants from the same source. The local sprite preserves each symbol viewBox; colors inherit from the interface.
